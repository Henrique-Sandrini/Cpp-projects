# C++ Projects Collection

## Overview

This repository contains a collection of **C++ projects developed for learning purposes**, organized in **progressive order**.  
Each project represents a step forward in complexity and knowledge, allowing a gradual understanding of the C++ language.

As the project number increases, the level of difficulty and conceptual depth also increases, culminating in the **core fundamentals of Object-Oriented Programming (OOP)**.

---

## Learning Progression

The projects are organized numerically (e.g., `project01`, `project02`, `project03`, ...).  
This numbering is intentional and represents the learning path:

- Lower-numbered projects focus on **basic programming concepts**
- Mid-level projects introduce **structured programming**
- Higher-numbered projects explore **Object-Oriented Programming fundamentals**

---

## Concepts Covered

### Beginner Level
- Basic syntax of C++
- Variables and data types
- Input and output (`cin`, `cout`)
- Conditional structures (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Basic functions

---

### Intermediate Level
- Modularization using functions
- Arrays and basic data structures
- Strings and string manipulation
- File handling (when applicable)
- Code organization and readability
- Introduction to problem-solving patterns

---

### Advanced Level (OOP Fundamentals)
- Classes and objects
- Encapsulation
- Constructors and destructors
- Access modifiers (`public`, `private`, `protected`)
- Methods and attributes
- Introduction to abstraction
- Foundational Object-Oriented Programming concepts

## How to Compile and Run

### Prerequisites
- C++ compiler (GCC, MinGW, or similar)
- Terminal or command prompt

### Example (GCC)

```
bash
g++ main.cpp -o program
./program
```
Replace main.cpp with the corresponding source file of each project.
